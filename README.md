# Quiz Game — Test Your Knowledge!

An interactive browser-based quiz game with 20 questions, score tracking and a clean mobile-friendly UI.

## 🔗 Live Demo
👉 [https://lively-cascaron-a72009.netlify.app](https://lively-cascaron-a72009.netlify.app)

## ✨ Features
- 🧠 20 general knowledge questions
- 📊 Real-time score tracking
- 📱 Fully responsive — mobile first design
- ⏱️ Question progress indicator
- 🔄 Play again functionality
- 💡 Hint system built in

## 🛠️ Built With
- HTML5
- CSS3
- Vanilla JavaScript

## 🚀 Getting Started

```bash
# Clone the repository
git clone https://github.com/anointedsolo11-tech/quiz-game.git

# Open in browser
open index.html
```

## 🎮 How to Play
1. Click **Start Quiz**
2. Answer each of the 20 questions
3. See your final score at the end
4. Click **Play Again** to restart
